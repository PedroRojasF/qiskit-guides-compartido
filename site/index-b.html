Qiskit

Todas las guías, contadas de principio a fin

✦ ✦ ✦

Este curso recorre, lección por lección, la documentación completa de IBM Quantum: cómo construir circuitos, cómo transpilarlos para un procesador real, cómo usar las primitivas Sampler y Estimator, cómo suprimir y mitigar el ruido, y cómo ejecutar, medir y administrar trabajos en hardware. Cada lección es una animación narrada con código que se ejecutó antes de publicarse, preguntas para comprobar lo aprendido y ejercicios para practicar.
